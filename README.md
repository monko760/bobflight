# BobFlight

Firmware and configurator developed together for the Holybro Kakute F7 HDV.

- `bobflight-firmware/`: firmware, board definitions, tests, and vendored dependencies.
- `bobflight-configurator/`: browser configurator and CLI protocol.

See BASELINE.md for the hardware-verified starting point. Build directories,
installed tools, node_modules, recovery copies, and HEX files remain local.

This is a local repository. No remote hosting is configured.
