# Governance — BobFlight Configurator

**Model:** Benevolent Dictator For Life (BDFL) / founder-maintained, with Configurator Lead as day-to-day maintainer under Robert / BobDroneCo.

## Decision authority

- **Roadmap, releases, and merge rights** for this repo rest with the Configurator Lead and people they (or Robert) explicitly appoint.
- Opening an issue, discussion, or pull request is a **proposal**, not a vote.
- Cross-cutting protocol changes that affect firmware should be coordinated with BobFlight FW Lead / PM.

## Maintainers

| Role | Powers |
|------|--------|
| Project lead (Robert) | Final say on license/policy, appointing leads |
| Configurator Lead | Merges, releases, path owners for UI/Protocol implementers |
| UI / Protocol implementers | PRs in owned paths; no unilateral license/governance changes |
| Triager (optional) | Labels only — no merge |
